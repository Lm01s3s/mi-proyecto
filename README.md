# 🫀 Gymkana Prep: Estudio Interactivo

Página web interactiva desarrollada para aprender y memorizar la anatomía humana mediante la asociación de imágenes y cajas de texto.

🌐 **[Ver y probar la página web aquí](https://lm01s3s.github.io/mi-proyecto/)**

---

## 🎯 Propósito
Facilitar el repaso ágil de órganos, músculos y estructuras del cuerpo humano de manera intuitiva.

## 🕹️ ¿Cómo se usa?
- **Sin complicaciones de formato:** Reconoce el texto sin importar si usas mayúsculas, minúsculas o tildes.
- **Lateralidad:** Para indicar si una estructura es derecha o izquierda, escribe `[Nombre] [D/I]`.
  - *Ejemplo:* `Fémur D` o `Pulmón I`.
